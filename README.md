# PCB-based-Electronic-Random-Number-Generator-0-9-
## Project Overview
This project is a PCB-based electronic random number generator developed using the **NE555 Timer IC, CD4026 Decade Counter IC, Common Cathode 7-Segment Display, and a Push-Button Switch**. The circuit generates and displays numerical outputs electronically, demonstrating the practical application of timer circuits, digital counters, and display interfacing.

The NE555 timer is configured to generate clock pulses, which are processed by the CD4026 decade counter to drive the 7-segment display. The push-button switch provides user interaction, allowing the circuit to operate as a compact electronic number generator.

## Components Used
- NE555 Timer IC
- CD4026 Decade Counter IC
- Common Cathode 7-Segment Display
- Push-Button Switch
- Resistors and Capacitors
- Printed Circuit Board (PCB)
- Power Supply and Connecting Components

## Working Principle
1. **Clock Pulse Generation:** The NE555 timer generates continuous clock pulses.
2. **Digital Counting:** The CD4026 counts the incoming pulses and produces the appropriate outputs for numerical display.
3. **Number Display:** The common cathode 7-segment display shows the corresponding digit.
4. **User Interaction:** The push-button switch provides manual control of the circuit, depending on the implemented switching arrangement.
